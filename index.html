EcoQuest

  • Game Design
  • UI Design
  • Business Analysis
  • Illustration

EcoQuest is an educational mobile game that teaches environmental awareness to Grade 4 students in Baliwag City. It was my capstone project and it won Best Capstone Project.

Role
Business Analyst / Lead UI Designer
Context
BSIT capstone, Baliwag Polytechnic College
Audience
Grade 4 students
Made with
Godot, Krita, FlipaClip, Procreate

(WHAT I DID)

  • Researched the topic and the audience
  • Wrote the game paper
  • Designed the UI and visual style
  • Helped build the game in Godot

Approach

  1. 01

    Research

    Looked at what Grade 4 students need to learn about waste: sorting, recycling and the collection schedule in Baliwag.

  2. 02

    Game paper

    Turned the research into a written plan for the game: goals, levels, mini-games and quiz questions.

  3. 03

    UI and art

    Designed the menus, bins and characters in Krita, Procreate and FlipaClip so the game feels friendly and clear for kids.

  4. 04

    Build and play-test

    Built the game in Godot and ran play sessions with Grade 4 students to see how they sorted waste and answered the quizzes.

MTech Inventory

  • Web App
  • UI Design
  • React
  • TypeScript

MTech Inventory is a web app for tracking stock across branches. Admins and staff sign in with different access, and the dashboard shows what needs attention first.

Type
Web app
Made with
React, TypeScript
Access
Admin and Staff login
Focus
Stock tracking and reports

(WHAT I DID)

  • Multi-branch stock tracking
  • Barcode scanning
  • Low stock alerts
  • Reports

Approach

  1. 01

    Sign in and roles

    Separate Admin and Staff logins so each person only sees what they need.

  2. 02

    Dashboard

    One screen that shows stock levels and what is running low.

  3. 03

    Branches and barcodes

    Track items per branch and scan barcodes to find or update them quickly.

  4. 04

    Reports

    Summaries of stock movement that are easy to read and check.

(WHAT I DID)

Approach

City Runner in Baliwag

  • Mobile Game
  • Godot
  • Game Design

Coffee Dash is a city-runner game set in Baliwag. You pick a character and run through the city while dodging traffic and a recycling truck.

Type
Mobile game
Made with
Godot Engine
Setting
Baliwag City
Title
Coffee Dash

(WHAT I DID)

  • Character select
  • Endless run through Baliwag
  • Score and best score
  • Game over screen

Approach

  1. 01

    Choose a character

    Two characters with their own short profile and favourite coffee.

  2. 02

    Run the city

    The street scrolls past local places, jeepneys and buses.

  3. 03

    Dodge obstacles

    Trucks and vehicles come in, and you move to avoid them.

  4. 04

    Beat your best

    The game over screen shows your score and best score so you want to run again.
